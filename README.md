# EduFlow App
### AI-Powered Dynamic Learning Roadmap Platform

EduFLow is a full-stack web application that generates personalized learning roadmaps using AI. Users can get a structured, week-by-week learning path for any topic, track their progress, and stay on course toward their learning goals.

---

## Features

- **AI-Generated Roadmap** - Enter a topic, goal, level and duration. Get a complete roadmap instantly powered by AI.
-  **Progress Tracking** - Mark Topic as not started, in progress , or completed. See your completion percentage in real time.
-   **JWT-Authentication** - Secure register and login with hashed passwords and token based auth.
-   **Protected Routes** - All roadmap and progress data is private to each other.
-   **Cascade Deletes** - Deleting a roadmap cleans up all related topics,  resources, and progress automatically.
